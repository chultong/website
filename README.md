# CHULTONG Landing Page

Vision AI와 AI Ops를 중심으로 한 철통의 반응형 기업 랜딩페이지입니다.

## 로컬 실행

별도 설치 없이 정적 파일로 실행할 수 있습니다.

```bash
python3 -m http.server 4173
```

브라우저에서 `http://localhost:4173`을 엽니다.

## 구성

- `index.html` — 페이지 구조와 콘텐츠
- `styles.css` — 반응형 디자인 및 모션
- `script.js` — 메뉴, 탭, 스크롤 인터랙션
- `assets/` — 히어로 비주얼 및 파비콘

## 사이트 메뉴

- 회사소개 — 회사의 방향, 성장 전략, 기술 생태계
- 솔루션 — 데이터센터, 병원·의료, 유통·대형마트, 발전·에너지, 스마트시티, 공공기관
- 제품 — AI 영상분석, AI 시스템 유지보수
- 고객문의 — 이메일 문의 및 주소 복사

메뉴는 현재 페이지의 해당 섹션으로 이동합니다. 산업별 주소로 직접 접속하면 해당 민간·공공 탭이 자동으로 열립니다. 데스크톱 하위 메뉴는 텍스트에 마우스를 올리거나 키보드로 포커스하면 열립니다. 모바일에서는 펼침 화살표를 제공하며, 키보드 이동과 Escape 닫기를 지원합니다.
